# 医学科普长图

当前版本：v1.6。

## 内容

- 用户提供文章或文案时，逐字保留标题、副标题、正文、关键数字、参考文献和免责声明，不擅自改写、删减、概括、补写或调整顺序。仅按用户要求删除“图1”“图2”之类的图号与图注；保留必要的示意插画。用户明确要求改写、摘要或其他改动时按当次要求执行。
- 对用户给出的文案先完整读取，识别标题、段落和需保留内容。文字太多时分成自然连续的多段，让每段字号清楚，再按原文顺序拼接成一张长图；也可按用户要求交付多张。
- 对医学内容按适用要求核查，发现实质性错误时不要悄悄更改原文；单独准确说明问题及依据，让用户决定是否修改。不可把存疑论断说成已验证。

## 视觉风格

- 以 `assets/seasonal-reference.jpg` 为风格参考：暖米白纸张底色、橘棕色标题与编号、深褐色易读中文字、柔和的浅绿色提示、温暖朴素的手绘水彩小插画、自然分段和足够留白，竖向长图适合手机阅读。
- 按用户认可的装饰效果处理文字：主标题采用深褐色、有手写感的清晰字体，可在字后添加淡杏橙色、不规则水彩笔刷底纹；小标题用橘棕色文字与浅杏色笔触衬底。正文保持深褐色、清晰易读，可在段落周围点缀少量浅绿色植物、细线、小圆点及淡色水彩色块；重点提示可使用柔和浅绿色底纹或细描边。整体保持暖米白纸张质感、自然留白和适合手机阅读的字号。背景装饰不得遮挡、替代或改变文字，不要每段都套用大面积色块或固定边框；根据内容灵活排版。
- 使用多张参考图，各有侧重：`assets/seasonal-reference.jpg` 参考米白底色、手绘笔触与图文气质；`assets/longform-reference.jpg` 参考长文章分段、插画搭配和整体长图节奏；`assets/approved-style.jpg` 参考标题水彩笔刷和装饰细节。只借鉴视觉风格，不照抄参考图的文字、主题、人物或将其短文布局当作固定模板。
- 生图工具支持多张参考时，按当前文案需要传入有关参考图；如只能使用一张，短文优先选择季节参考图，长文优先选择长文参考图。参考图不可用时按风格要求执行并如实说明；长文在自然段处分段制作并按顺序拼接，不为适应画幅缩小正文或删改内容。
- 图文布局以参考图为目标：为各主题选择足够醒目且与内容对应的独立插画，不要把所有图固定为右侧小缩略图。短段可左右排列；长段优先让插画占据较宽区域，放在标题后、自然段之间或正文之后。检查人物本身在画布中的可见大小，以及插画自身是否留有大量空白；必要时调整尺寸和布局。若生图结果是一张多图拼版，须在允许的环境下逐幅分离或重新生成单图，检查画面边界、医学动作和清晰度，避免把整张拼版当成单个插画。
- 插画与段落内容相匹配，专业但亲切，避免过度装饰。默认不添加作者、医生姓名、医院或科室署名、标志、二维码；用户另有要求时遵照当次要求。
- 参考图仅定义视觉与排版风格，不复制其中的主题或文案。为医学解剖、动作及图示准确性进行检查。

## 已确认的文字和排版效果

- 标题设计：主标题深褐色、有清晰起收笔和粗细变化的手写楷书，章节标题橙棕色、较小且轻盈；主标题与章节标题字号约 1.5–1.6:1。避免只放大正文或使用膨胀粗黑字。淡杏色底纹随文字长短延伸，装饰少量且不遮字；长标题优先按短语分行，不删改标题。生图路线用这些要求生成并检查标题；离线默认标题使用霞鹜臻楷 Slab GB，正文保留霞鹜文楷，缺字按现有回退检查处理。离线字体不等同于生成的毛笔字。

- 避免将每幅插画放入固定矩形卡片：透明插画按可见轮廓为正文留出安全间距，正文不得压住人物；不透明图无法按人物轮廓绕排，应先取得合适的独立插画。提醒背景使用无描边、边缘柔和的不规则浅绿底纹。标题、插画与正文共同形成自然图文关系。离线程序的简化底纹不等同于原生水彩画。

- `assets/typography-reference.png` 是用户认可的文字及图文样张：参考手写感、正文可读性、淡杏色标题笔刷、浅绿色提示底纹和自然的图文搭配。只借鉴风格与比例，不复制样张的文案、疾病或人物。
- 原生生图时将相关参考图实际传入工具（支持时），明确要求清晰的中文手写楷书气质、深褐色正文、温暖米白纸底、二维卡通水彩插画；正文要适合手机阅读。提示和正文必须保持原文，不凭生成结果假定文字准确，逐字核对并修正。
- 以 1080 像素画布宽度为例，正文建议从 42–48 像素开始，根据字体与最终展示效果调整；内容较多时延长或分段拼接，不为容纳内容缩小到难以阅读。短文字与插画自然并排，优先以完整自然段或完整句子作为并排与通栏的切换位置，避免句子中途转栏；剩余正文通栏。按文字和插画实际高度布局，避免大块空白。优先在标点处换行，检查词语被拆开、行尾或行首孤字及段落间距；正文段内行距适中、步骤紧凑、章节间留白。
- 对已有提醒可用淡绿底突出，标题使用淡杏色笔触；不得凭空添加标签或修改文字。插画必须表达相应动作与情境，避免不同主题重复使用不相关插画。
- 离线渲染默认使用自带的霞鹜文楷 Regular，提供清晰的楷书感；缺失时回退思源黑体。可通过 `--font` 和 `--title-font` 指定其他字体，检查字形覆盖；字形缺失时应使用覆盖该字符的字体，不得删改原文。字体和布局均会影响效果，离线画面不保证等同生图样张。

## 图片生成路线

- 路线优先级：用户本次明确要求 > 宿主（当前 Agent）自带的图片生成能力 > 用户提供或授权的外接生图服务 > 本地素材库。检查当前实际工具与权限；不要根据模型名称或其自述猜测是否可调用。
- 宿主自带生图能力时，必须优先用宿主自己的模型为当前主题生成原创插画或画面。不要因为文章较长、中文易错、医学科普或离线文字更可靠而擅自退回固定素材库，也不要把使用生图当成需要额外批准的可选方案；用户明确要求只用素材或本地模式时除外。
- 宿主没有自带生图能力时，可询问用户是否已有现成可用的外接生图服务（由用户自行配置的 API 等）；只有用户明确提供或授权后才能调用，不得擅自启用付费接口，也不得把任何具体账号、密钥或服务商写死在技能里。外接服务同样按本节的视觉要求生成，并检查实际输出。
- 有生图能力时，主动要求生图工具为整张长图或各段制作统一的手绘水彩视觉：暖米白纸感、淡杏橙不规则笔触衬底、浅绿植物点缀、柔和手绘插画与自然留白，参考上面所列样张及各自作用。可以直接生成分段完整画面，或生成留有清晰文字区域的无字原创画面后再排原文；无论哪条路线都要检查整个画面的图文比例与装饰，不能只画一组孤立小插画就算达到目标。文字密集时分段，不删除或改写原文；用户另有要求时优先遵从。
- 将参考样张实际传给支持参考图的生图工具，不要只告知自己“已参考”。明确要求二维卡通手绘水彩插画：简化、亲切的人物造型，清晰柔和的描边，轻盈水彩色块，主体鲜明，装饰和背景简洁；不要写实摄影、照片质感、3D 渲染或浓重的照片式场景。只参考风格，不复制参考图的文字、疾病或人物。若工具不支持输入参考图，就用以上具体描述，检查实际输出；出现照片式人物或写实场景时重新生成或如实说明，不要当作已符合要求。
- 生成用于后期排版的单幅插画时优先请求透明背景的独立人物或主题元素，避免四周可见的矩形底色；环境必不可少时使用边缘自然消散的水彩场景。实际检查透明通道及可见边缘，不要只因文件是 PNG 就认为透明；若是色块矩形，在工具与权限允许时重新生成、处理背景或保留并向用户说明，避免裁掉动作、人体或医学细节。
- 在生成画面及最终排版中主动交替运用左右图文、上下图文与段落之间插画；不能所有章节都套用“图片上、文字下”的相同排列。长段可让开头几行与插画并排，其余文字占整行；字符很多时延长画布或分片拼接，不缩小文字或删文。若不使用本技能的排版脚本，也必须检查图文大小、方向和章节间变化。
- 检查长图在手机上按宽度显示时的可读性，正文、警示信息和数字不能细小或模糊；不要用缩小字号容纳全文。检查段落与插画之间是否有过大的空白，缩短不必要空隙，并让相邻图文保持关联。用户给出医学动作时核对人物体位与运动方向；确需用箭头或分解动作说明时不改变文案。
- 原文准确性与图片生成可以同时满足：优先让生图工具制作无文字插画，再在宿主允许的情况下用排版工具逐字排入原文，或使用可用的图像编辑能力。保留排版顺序，分段核对；不要声称生图模型能够保证文字零误差。如果环境不允许组合，继续使用可用图像工具生成并严格校对；不能声称做了未完成的核对。
- 宿主没有生图能力、用户也没有可用的外接生图服务，或实际调用失败时，才使用本地素材库与排版程序；向用户简短说明使用该路线的原因。其他条件相同时不能仅因离线方案更方便或文字更可靠而跳过图片生成。
- 用户明确要求无接口/纯离线时，按用户指令使用离线素材和排版。素材不足时留白或明确告知，不能把不相关的图当作医学示意或声称生成了新插画。不可在用户未授权时启用付费 API。

### 本地排版工具

- `scripts/render_long_image.py` 用 Python 3、Pillow 与技能自带中文字体生成 PNG，不依赖图片 API；支持时用户亦可指定完整字体。输入 UTF-8 JSON，按原文顺序完整填入：
- 离线程序自动使用 `assets/decor/` 中的浅橙水彩笔触与植物点缀；素材缺失时采用简化图形回退。这些固定素材无法针对不同主题自主创作，效果与参考图仍可能有差异。不要用“生成插画”作为忽略整张图的标题背景、留白和图文关系的理由；检查最终成品，效果不足时继续调整。没有生图能力时应如实说明画面能力限制。

```json
{"title":"原文标题","subtitle":"原文副标题","sections":[{"heading":"原文小标题","body":"原文段落","illustration":"low-back"},{"heading":"另一小标题","body":"原文段落"}]}
```

- 每段可选 `layout`；默认 `auto` 按是否有插画、正文长度和警示词选择布局。可设为 `text-left`（文字左）、`text-right`（文字右）、`image-inline`（完整短段与插画并排，其余文字通栏；首段过长时改为通栏排版）、`image-top`（插画在正文上方）、`image-middle`（插画在首个自然段之后）、`image-bottom`（插画在正文后）、`text-only`（纯文字）或 `warning`（警示框）。图文布局需提供匹配的独立插画；不能增删改写原文来适应版式。程序只去除全透明边缘，遇不透明背景会提示检查。可在对应段落设置 `"illustration_edge":"feather"` 柔化插画边缘，原文件不变；这不是真正的背景移除，只适合主体远离边缘的场景，必须检查未淡化医学细节。自动排版是规则选择，不是对医学内容的智能判断，必须检查语义、动作和实际视觉效果。
- 使用默认素材运行：`python scripts/render_long_image.py --input 文章.json --output 长图.png`。素材键及含义见 `assets/illustrations/manifest.json`；无合适素材时省略 illustration。若程序提示缺字，使用覆盖这些字符的中文字体，传入 `--font 字体路径` 或设置 `HEALTH_IMAGE_FONT`，再重新检查完整输出，不要替换或删除原文。
- 可选用本机已有的、授权允许使用的中文手写字体为标题和小标题增加手写感：`--title-font 字体文件路径`；正文仍使用默认字体或 `--font` 指定的字体。标题字体缺字时回退正文主字体；仍缺字则报错，不更换或删除文字。技能自带霞鹜文楷 Regular；自定义字体须确认字形覆盖。
- 组合原创插画和程序排字时，允许的情况下先将生图工具生成的无文字 PNG 放在临时目录，按段命名如 `winter-care.png`，在对应段落设 `"illustration":"winter-care"`，再运行 `python scripts/render_long_image.py --input 文章.json --output 长图.png --illustrations-dir 临时目录`。该选项读取指定目录，不会同时使用默认素材；需混用时先在临时目录准备所需图片。不得绕过宿主对图像编辑工具的要求。
- 长文可分组渲染并在允许的环境下按顺序拼接，核对整篇内容。程序仅作排版，不会进行医学事实核查。最终图片必须真实产出。
- 若既无图片生成也无运行程序能力，如实说明限制，不假装生成了图片。

## 制作与核对

1. 按字量合理分段，优先保留内容完整与可读性。用户已允许多张分段生成后拼接。
2. 对每个片段与原文逐段对照，检查标题、全部正文、关键数字、红旗信息、引用、标点和是否有乱码或遗漏；尤其注意生成模型可能改动文字，不要仅凭提示词声称逐字一致。若发现问题，修复后再次核对；确实无法完全核实时，如实说明。
3. 分段拼接时保持顺序、统一宽度、视觉连贯，不裁掉文字与插画。交付完整长图；根据需要提供分段文件，并依环境要求保存最终可下载成果。
4. 新对话中，用户要求“科普图片”“科普长图”“宣教长图”等且没有特别指定风格时，默认使用此模式。明确的当次指令始终优先。
