# 医学科普长图 Skill

一个用于制作中文医学科普图片和宣教长图的可复用技能。将用户提供的文案按段落完整呈现，配合温暖的手绘风格；内容较长时分段制作并按顺序拼接。

## 特点

- 默认保留用户提供的正文、数字和参考文献，不擅自改写。
- 米白底、橘棕色标题、手绘插画，适合手机阅读。
- 默认不署名；用户可以随时指定不同风格或修改要求。
- 分段核对文字、图示和医学信息，发现实质性疑点时单独提示。

## 使用

将 `health-education-long-image/` 安装到支持 `SKILL.md` 的技能环境中。请求示例：

> 使用医学科普长图技能，把这篇文章做成科普长图。

需要可用的图像生成工具。技能提供工作流程，不保证所有平台、工具或账户均支持自动调用、长图拼接或完全准确的图中文字。生成结果应逐段核对。

## 文件

- `health-education-long-image/SKILL.md`：技能触发条件和操作说明。
- `health-education-long-image/agents/openai.yaml`：技能界面元数据。

本项目使用文字描述风格，不包含原参考图。
