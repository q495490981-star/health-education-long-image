# 医学科普长图

当前版本：v2.0。

## 内容

- 用户提供文章或文案时，逐字保留标题、副标题、正文、关键数字、参考文献和免责声明，不擅自改写、删减、概括、补写或调整顺序。仅按用户要求删除“图1”“图2”之类的图号与图注；保留必要的示意插画。用户明确要求改写、摘要或其他改动时按当次要求执行。
- 对用户给出的文案先完整读取，识别标题、段落和需保留内容。文字太多时分成自然连续的多段，让每段字号清楚，再按原文顺序拼接成一张长图；也可按用户要求交付多张。
- 对医学内容按适用要求核查，发现实质性错误时不要悄悄更改原文；单独准确说明问题及依据，让用户决定是否修改。不可把存疑论断说成已验证。

## 视觉设计与不变量

先规划设计，再选择参考图或写生图提示。全文和医学信息准确、对比充分、手机阅读清楚、标题层次分明、插画语义及动作正确是任何样式的共同要求；背景颜色、插画技法、标题书体、装饰和图文构图可随内容和用户偏好变化。用户当次指定的样式最高优先；既有用户认可的暖色水彩和手写标题可以继续选择，但不作为所有主题的唯一方案。不能为了视觉变化增删改写原文，也不能把每个章节机械地套进同一种构图。

通读全文后，先确定读者、主题、阅读任务与需特别准确表达的画面，再为本篇形成一份简短内部设计方案：主视觉概念、配色及对比、标题与正文字体气质、插画形式、各段图文关系、提示处理方式。选用用户指定的方向或依据文案自主选择，不必将推理过程写进成图。以下方向只是起点，不是主题强制映射；可按内容混合或自拟其他方案：

- **温暖手绘叙事**：轻水彩人物和柔和笔触，手写标题，图文自然交错；适合日常照护或情感亲切的主题。
- **食材图鉴**：围绕食材形态或烹饪情境绘制局部插画，以食材分组安排图文，颜色由食材决定；适合饮食科普。
- **动作分解**：按原文动作顺序安排清晰人物示意及必要的方向线，文字紧邻动作；适合康复锻炼，体位和方向须检查。
- **清晰知识图解**：较克制的插画、线条或色块，通栏文字配重点示意；适合机制解释或就医提示，解剖及指示必须准确。

同一篇长图保持色彩、标题和正文系统一致，但章节根据文案节奏变化；不同文章不必为了变化而随机换色。多个方案的差别应同时体现在构图、字体气质、插画技法或信息组织等方面，不以改变配色或背景小装饰冒充完全不同的设计。若使用用户认可的既有风格，依照用户意愿保留其特征。

## 风格参考与图文布局

- 原先经用户认可的暖色手绘风格可参考 `assets/seasonal-reference.jpg`：暖米白纸张、橘棕标题、手绘水彩与自然留白。它是可选择的方向，并非所有方案的默认约束。正文、背景与重点提示保持对比、可读与协调，装饰不得遮挡、替代或改变文字；植物只在适合时使用，不自动套用。
- 使用参考图时各有侧重：`assets/seasonal-reference.jpg` 参考米白底色、手绘笔触与图文气质；`assets/longform-reference.jpg` 参考长文章分段、插画搭配和整体长图节奏；`assets/approved-style.jpg` 参考标题水彩笔刷和装饰细节。另有三种原创风格模板：
  - `assets/style_references/apricot-brush.png`：暖杏橙与深棕、较有力度的手写标题、轻快的左右图文关系。
  - `assets/style_references/calm-blue.png`：米白与浅蓝、深蓝标题、安静清爽的图文与较多留白。
  - `assets/style_references/soft-sage.png`：米白、柔和灰绿与暖棕、温和手绘人物、交替布局。
- 这几张现有样张构图相近：按设计方案只选择相关样张及要借鉴的维度（如纸感、笔触或长文节奏），不要把配色、标题和构图一并锁定。不同方向没有合适样张时允许不传现有样张，用具体设计说明制作；若用户要求参考图，优先传入所指定的图。不能照抄样张中的文字、主题、人物、动作或医学内容，也不能声称参考图已传入而实际未传。同一长图各段保持统一视觉系统。
- 为各主题选择与内容对应的图示，按照选定的设计决定插画比例及位置。短段可左右排列，也可以用通栏或动作分解；长段不强制将插画放大。检查人物在画布中的可见大小和插画留白；必要时调整。若生图结果是一张多图拼版，须在允许的环境下逐幅分离或重新生成单图，检查画面边界、医学动作和清晰度，避免把整张拼版当成单个插画。
- 长文先按原文自然段和完整句子规划连续片段及插画位置，不预设固定段数；未提供总标题时不自行补写，跨片续文不重复章节标题。首句或短段可与相关插画左右并排，较长内容在句末或段末自然转为通栏；不同章节依据内容变化布局，让文字、图像和留白保持关联。正文背景须保证对比；只突出原文已有的注意事项或提醒，不能添加新标签或改写原句。段内行距适中、段落紧凑，章节之间留出空间；按手机宽度检查文字和插画大小，不以缩字容纳长文。
- 对已生成长图优化排版时，可使用现有画面和与目标风格相关的参考指导生图工具调整段落与图文位置，不复刻参考图文字、人物或医学内容。无论是否改动某一局部，每个编辑过的片段都需与用户原文完整对照，包括标题、续段衔接、数字、否定词、提醒与标点；有遗漏或错字则修复后再检查。最后按相同宽度拼接并查看接缝、全文顺序和章节标题一致性，不能只检查画面是否美观。
- 插画与段落内容相匹配，专业但亲切，避免过度装饰。默认不添加作者、医生姓名、医院或科室署名、标志、二维码；用户另有要求时遵照当次要求。
- 参考图仅定义视觉与排版风格，不复制其中的主题或文案。为医学解剖、动作及图示准确性进行检查。

## 已确认的文字和排版效果

- 标题设计：主标题要醒目、明显大于章节标题，颜色与背景对比充分；书体、笔触和构图依据设计选择。此前用户认可的手写毛笔楷书与浅色水彩底板可作为暖色手绘方案，不强加给其他方案。以 1080 像素宽画布为例，主标题可从约 96 像素起、章节标题约 50 像素，根据长度和可读性调整；长标题按短语自然分行，不删改内容，也不缩小正文。离线默认主标题使用霞鹜臻楷 Slab GB，章节标题与正文使用霞鹜文楷，缺字按现有回退检查处理；离线字体不声称等同原生毛笔字。

- 主标题不固定为一种模板：依据主题、篇幅和用户偏好选择清晰醒目的字体与构图，例如自然毛笔楷书配水彩底、温润行楷配留白，或简洁字体配主题图形。风格变化应体现在字体、插画和构图，而不只是换装饰；保留足够对比、可读性与主次层级，禁止改动标题文字。首次采用时可根据主题自主选择，不必询问用户。

- 测试或提供多个主标题样式时，为每款制定明确视觉方案，至少同时区分两至三项：字体气质、颜色、底纹、构图。不得为区分样式改写文字或牺牲可读性。参考图仅用于所选维度，不将参考图的字形或标题构图设为必须模仿；生成时明确写出本款正向特征和不能照抄的参考元素。不同风格生成后按同宽并排检查字形、构图、底纹与原文；若仍趋同，应如实说明并调整，而非声称差异明显。

- 分段生图时先确定全篇统一的标题层级：仅第一段出现整篇主标题，后续各段的标题均是章节标题，即使单独生成也不能当作新的主标题。每段提示词写明选定字体与标题层级，主标题明显大于章节标题；颜色及有无底纹遵循选定样式，正文仍清楚易读。完成后把各段按同一宽度比较：若章节标题与主标题视觉重量接近或底纹遮字，调整对应段并重新核对原文；长章节标题自然分行，不减小正文或省略文字。

- 全篇章节标题检查必须包含首段里的第一章标题；首段同时含主标题并不是跳过第一章的理由。先将不同尺寸片段按最终交付宽度等比例预览，再逐一比较所有章节标题的字号、粗细、颜色和笔触底纹；如果首段因放大而导致第一章标题与其他章节不一致，也须调整并核对该段全部文字。修改不能仅依靠声明“已统一”，应检查实际输出。

- 用户要求由生图统一章节标题时，继续使用 A 路线：选择或生成一张已检查过的章节标题样式参考，在工具支持时把同一张参考传给每个相关片段，仅参考字形与版式，不复制其中的文字。每段提示词明确使用同一套相对于最终成图宽度的字高、字重、颜色及选定底纹；长标题自然分行而不是擅自缩小字号。拼接前按最终宽度等比例比较包括首章在内的全部章节标题，发现差异则用生图或可用图像编辑能力调整，再逐字核对修改后整段内容。不能保证模型一次生成完全一致；如果多次尝试仍不能兼顾一致性与原文准确，如实说明问题，仅在用户同意后改用人工排字。

- 按主题规划稀疏、多样的装饰，而不是给每一段重复添加绿叶：先通读各段，挑选与内容和医学情境相关的简单、准确且不干扰文字的小元素；其余空间可用短线、小点、水彩笔触或留白。植物只在适合时少量使用，参考图中反复出现的绿叶不是必须复制的模板。每段生图提示词写明该段选择的装饰和避免重复植物；合成后检查全篇是否单调重复、是否误导医学含义。离线没有匹配素材时使用简洁笔触或留白，不自动给每个标题配植物，不以不相关图形充当医学示意。

- 不必将每幅插画放入固定矩形卡片：透明插画按可见轮廓为正文留出安全间距，正文不得压住人物；不透明图无法按人物轮廓绕排，应先取得合适的独立插画。提醒背景由选定配色与构图决定，文字对比要充分。标题、插画与正文共同形成自然图文关系。离线程序的简化底纹不等同于原生水彩画。

- `assets/typography-reference.png` 是用户认可的文字及图文样张：参考手写感、正文可读性、淡杏色标题笔刷、浅绿色提示底纹和自然的图文搭配。只借鉴风格与比例，不复制样张的文案、疾病或人物。
- A 路线生成时按方案选用相关参考图，使用时须实际传入支持参考图的工具；将选定书体气质、配色、插画技法和布局明确写入提示，正文须适合手机阅读。提示和正文必须保持原文，不凭生成结果假定文字准确，逐字核对并修正。
- 以 1080 像素画布宽度为例，正文建议从 42–48 像素开始，根据字体与最终展示效果调整；内容较多时延长或分段拼接，不为容纳内容缩小到难以阅读。短文字与插画自然并排，优先以完整自然段或完整句子作为并排与通栏的切换位置，避免句子中途转栏；剩余正文通栏。按文字和插画实际高度布局，避免大块空白。优先在标点处换行，检查词语被拆开、行尾或行首孤字及段落间距；正文段内行距适中、步骤紧凑、章节间留白。
- 对已有提醒可用协调的底色突出；标题可使用笔触或留白，不得凭空添加标签或修改文字。插画必须表达相应动作与情境，避免不同主题重复使用不相关插画。
- 离线渲染默认使用自带的霞鹜文楷 Regular，提供清晰的楷书感；缺失时回退思源黑体。可通过 `--font` 和 `--title-font` 指定其他字体，检查字形覆盖；字形缺失时应使用覆盖该字符的字体，不得删改原文。字体和布局均会影响效果，离线画面不保证等同生图样张。

## 图片生成路线

- 路线优先级：用户本次明确要求 > A 路线（宿主或用户授权的外接生图工具，直接生成含文字的完整画面） > B 路线（无文字画面/插画 + 用排版工具逐字排入原文） > 仅用本地素材库。先检查当前实际工具与权限；不要根据模型名称或其自述猜测是否可调用。
- 默认走 A 路线：宿主自带生图能力时用宿主自己的模型；宿主没有时，可询问用户是否有现成可用的外接生图服务（由用户自行配置的 API 等），只有用户明确提供或授权后才能调用，不得擅自启用付费接口，也不得把任何具体账号、密钥或服务商写死在技能里。
- A 路线直接生成含标题、正文和插画的整张画面；长文按原文自然段分段生成，再按顺序拼接，不删改原文。使用参考样张时实际传给支持参考图的工具；明确提示本篇方案所选的画风、背景、标题、图文结构和借鉴维度，不将参考图中的植物、标题字形或构图设为固定要求。按各段主题指定装饰和插画；只参考风格，不复制参考图的文字、疾病或人物。医学图示应清晰准确，选择写实或 3D 等表现形式时同样要核验，用户另有要求时优先遵照。
- A 路线必须逐字核对图内文字：发现错字、漏字、改写或乱码，重新生成该段，或用可用的图像编辑能力局部修正。每次编辑或重新生成后都要重新核对该段全部文字和插画，而不只检查目标区域；尤其检查数字、否定词、就医提醒和标题，因为图像编辑可能连带修改其他内容。不能只凭提示词声称文字准确，无法完整核实时应如实说明，也不能因为核对麻烦就擅自改走 B。确实多次重生成仍无法写对时，才可以改走 B，并告诉用户原因、注明哪些文字是排版排入的。
- A 路线模型选择建议：为达到最佳成图效果，A 路线应将生成图片内的全部文字与原文逐字对比，发现错字、漏字、改写或乱码后进行修正和复核。长文案尤其容易产生文字错误，通常需要多轮分段重生成；因此**不建议使用中文文字生成能力较差或按单张图片收费的模型执行 A 路线**，以免无法保证文字质量或因反复重生成带来较高成本。若可用模型存在上述限制，应在生成前明确提示质量与费用风险，并尊重用户对工具及成本的选择。
- B 路线用于生图文字不可靠，或用户明确要求“先生成无字画面再排字”的情况：生成无文字插画或留有清晰文字区域的无字画面，再用排版工具逐字排入原文，分段核对；生成用于后期排版的单幅插画时优先请求透明背景的独立人物或主题元素，避免四周可见的矩形底色，实际检查透明通道和可见边缘。
- 宿主没有生图能力、用户也没有可用的外接生图服务，或实际调用失败时，才使用本地素材库与排版程序；向用户简短说明使用该路线的原因。其他条件相同时不能仅因离线方案更方便或文字更可靠而跳过生图。
- 用户明确要求无接口/纯离线时，按用户指令使用离线素材和排版。素材不足时留白或明确告知，不能把不相关的图当作医学示意或声称生成了新插画。不可在用户未授权时启用付费 API。
- 无论 A 还是 B，都要检查整张长图的图文比例、装饰与留白，不能只画一组孤立小插画就算完成；主动交替运用左右图文、上下图文与段落之间插画，不能所有章节都套用“图片上、文字下”的相同排列；字符很多时延长画布或分片拼接，不缩小文字或删文。
- 检查长图在手机上按宽度显示时的可读性，正文、警示信息和数字不能细小或模糊；不要用缩小字号容纳全文。检查段落与插画之间是否有过大的空白，缩短不必要空隙，并让相邻图文保持关联。用户给出医学动作时核对人物体位与运动方向；确需用箭头或分解动作说明时不改变文案。

- 每段可选 `layout`；默认 `auto` 按是否有插画、正文长度和警示词选择布局。可设为 `text-left`（文字左）、`text-right`（文字右）、`image-inline`（完整短段与插画并排，其余文字通栏；首段过长时改为通栏排版）、`image-top`（插画在正文上方）、`image-middle`（插画在首个自然段之后）、`image-bottom`（插画在正文后）、`text-only`（纯文字）或 `warning`（警示框）。图文布局需提供匹配的独立插画；不能增删改写原文来适应版式。程序只去除全透明边缘，遇不透明背景会提示检查。可在对应段落设置 `"illustration_edge":"feather"` 柔化插画边缘，原文件不变；这不是真正的背景移除，只适合主体远离边缘的场景，必须检查未淡化医学细节。自动排版是规则选择，不是对医学内容的智能判断，必须检查语义、动作和实际视觉效果。
- 使用默认素材运行：`python scripts/render_long_image.py --input 文章.json --output 长图.png`。素材键及含义见 `assets/illustrations/manifest.json`；无合适素材时省略 illustration。若程序提示缺字，使用覆盖这些字符的中文字体，传入 `--font 字体路径` 或设置 `HEALTH_IMAGE_FONT`，再重新检查完整输出，不要替换或删除原文。
- 离线排版的 JSON 顶层可设 `"title_style"`：`"brush"` 是醒目楷书配水彩底纹（默认），`"ink"` 是深色楷书配细线和留白，`"soft"` 是较温和的文楷配浅笔触。根据主题或用户偏好选择，不自动随机；显式指定 `--title-font` 时主标题使用该字体。三种是离线字体与装饰的组合，不等同于生图的手写毛笔字。风格应保持清晰、大小层级一致，长标题可自然换行。
- 离线 JSON 顶层可设 `"palette"`：`"warm"`（默认）、`"calm-blue"` 或 `"soft-sage"`。该选项调整排版颜色，不会改变插画本身、段落布局或把生图参考模板完整套到离线图上；应实际查看文字对比与配色效果。
- 可选用本机已有的、授权允许使用的中文手写字体作为主标题字体：`--title-font 字体文件路径`；章节标题和正文使用默认字体或 `--font` 指定的字体，形成明显层级。主标题字体缺字时回退正文主字体；仍缺字则报错，不更换或删除文字。技能自带霞鹜文楷 Regular；自定义字体须确认字形覆盖。
- 组合原创插画和程序排字时，允许的情况下先将生图工具生成的无文字 PNG 放在临时目录，按段命名如 `winter-care.png`，在对应段落设 `"illustration":"winter-care"`，再运行 `python scripts/render_long_image.py --input 文章.json --output 长图.png --illustrations-dir 临时目录`。该选项读取指定目录，不会同时使用默认素材；需混用时先在临时目录准备所需图片。不得绕过宿主对图像编辑工具的要求。
- 长文可分组渲染并在允许的环境下按顺序拼接，核对整篇内容。程序仅作排版，不会进行医学事实核查。最终图片必须真实产出。
- 若既无图片生成也无运行程序能力，如实说明限制，不假装生成了图片。

## 制作与核对

1. 按字量合理分段，优先保留内容完整与可读性。用户已允许多张分段生成后拼接。
2. 对每个片段与原文逐段对照，检查标题、全部正文、关键数字、红旗信息、引用、标点和是否有乱码或遗漏；尤其注意生成模型可能改动文字，不要仅凭提示词声称逐字一致。若发现问题，修复后再次核对；确实无法完全核实时，如实说明。
3. 分段拼接时保持顺序、统一宽度、视觉连贯，不裁掉文字与插画。交付完整长图；根据需要提供分段文件，并依环境要求保存最终可下载成果。
4. 按设计方案检查风格和布局是否真正适合文章，而非仅检查是否比旧版短；如果用户要求多种风格或跨主题测试，将实际生成的样图以相同宽度对照字体气质、插画形式与构图，仍趋同时调整或如实说明。未实际做跨主题生成时不要声称已验证风格多样性。
5. 新对话中，用户要求“科普图片”“科普长图”“宣教长图”等且没有特别指定风格时，按本技能通读内容并选择设计。明确的当次指令始终优先。
